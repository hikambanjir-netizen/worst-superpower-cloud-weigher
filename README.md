The Cloud-Weigher: I can instantly know the exact weight of any cloud I look at, to the gram — a skill no cloud, farmer, or pilot has ever needed. The most useless superpower ever invented, in one line of 127 characters.

## Run it

```sh
python3 main.py
```

It writes the one-line superpower to `/output/entry.txt`.
